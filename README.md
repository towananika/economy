# とわなにか

人生の3つの資産（お金・体・つながり）を一目で。公開: 入口は https://towananika.github.io/hibiki/ 、お金は https://towananika.github.io/economy/money/

- `index.html` は hibiki への転送（入口は towananika/hibiki）
- `money/` お金（金利メーター、配分、週間レポート `money/report.html`）
- `health/` 体、`relations/` つながり（準備中）
- 直下の `report.html` などは `money/` への転送
